## 🌟 Overview

**UtkalSarathi** is an enterprise-grade, full-stack travel intelligence and cultural preservation platform designed and engineered from the ground up to empower travellers across the 30 districts of Odisha, India.

Architected with first-class support for both **Desktop (macOS & Windows 11)** and **Mobile Phone Apps (Android & iOS PWA / TWA)**, the platform bridges historical epigraphy (Archaeological Survey of India field reports, rock edicts, copper plates, and palm-leaf manuscripts) with modern real-time transit pricing, emergency disaster protocols, and cutting-edge acoustic voice synthesis.

## 📱 Mobile Phone App Deployment (Android & iOS)

UtkalSarathi provides an authentic smartphone experience engineered specifically for mobile phone ergonomics:

### 🤖 Android Phone App (PWA & TWA)
* **1-Click Home Screen / APK Installation:** Built with `vite-plugin-pwa` generating full Chromium Web App Manifest (`manifest.webmanifest`), `sw.js` service worker, and 192px/512px maskable icons.
* **Android Bubblewrap / TWA Ready:** Compatible with Google Play Store Trusted Web Activity (TWA) generation for native `.apk` and `.aab` publishing.
* **Mobile Bottom Navigation Bar:** Dedicated phone navigation bar with touch-optimized targets (`Explore`, `Map`, `Transit`, `Utkal Katha`, `Cuisine`, `SOS 112`) and safe-area padding (`env(safe-area-inset-bottom)`).
* **Material You Accents & System Bar:** Android status bar coloring (`#991b1b` terracotta theme) and responsive touch highlights.
* **Offline Travel Packs:** Pre-caches emergency helplines, hospital directories, and transit matrices for zero-connectivity journeys in rural Odisha.

### 🍎 Apple iOS Phone App (iPhone & iPad)
* **Safari Add to Home Screen:** Configured with iOS `<meta name="apple-mobile-web-app-capable" content="yes">`, `<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent">`, and 180x180 `apple-touch-icon.png`.
* **Fullscreen Native Feel:** Removes Safari navigation chrome when launched from the iPhone home screen.

## 🚀 Quickstart & Deployment

### Prerequisites
* **Node.js**: v20+ or v22+
* **npm**: v10+

### Installation & Local Run

```bash
# Clone the repository
git clone https://github.com/abhishekpanda/utkalsarathi-odisha.git
cd utkalsarathi-odisha

# Install dependencies
npm install

# Run cross-platform dev server on macOS / Linux
npm run dev:mac

# Run on Windows
npm run dev:win

# Run test suite (24 unit tests across all modules)
npm test

# Build production bundle (includes PWA Service Worker & Workbox)
npm run build

# Start production server
npm start
```

### Building Android APK (TWA)
```bash
# Install Bubblewrap CLI
npm install -g @bubblewrap/cli

# Initialize Android project from manifest
bubblewrap init --manifest=https://your-domain.com/manifest.webmanifest

# Build Android release APK
bubblewrap build
```
